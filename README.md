# Gestión del Mundo Barbie 🌸💄🚗

Este proyecto es una **aplicación web en PHP** creada para registrar personajes del universo Barbie, sus profesiones, habilidades y salarios. Además, incluye un **panel de estadísticas** con gráficos para visualizar información relevante.

## Funcionalidades principales

### 👩‍🎤 Registro de Personajes
- Identificación, nombre, apellido y fecha de nacimiento.
- Foto del personaje.
- Profesión o rol en el mundo Barbie.
- Registro ilimitado de personajes.

### 💼 Registro de Profesiones y Salarios
- Nombre de la profesión (Ej: Veterinaria, Diseñadora, Chef, Científica…)
- Categoría (Ciencia, Arte, Deporte, Entretenimiento…)
- Nivel de experiencia (Principiante, Intermedio, Avanzado)
- Salario mensual estimado ($USD)
- Permite asociar múltiples profesiones a cada personaje.

### ✏️ Modificación de Datos
- Editar o eliminar información de personajes y profesiones.

### 📊 Panel de Estadísticas (Dashboard)
- Cantidad total de personajes y profesiones.
- Promedio de profesiones por personaje.
- Edad promedio de los personajes.
- Distribución de personajes por categoría de profesión.
- Nivel de experiencia más común.
- Profesión con mayor y menor salario.
- Salario promedio.
- Personaje con salario más alto.
- Gráficos interactivos (Chart.js) de distribución de salarios por categoría.

### ⚡ Extras
- Registro de habilidades especiales de cada personaje (habilidad, tipo y nivel).

## Tecnologías usadas
- PHP puro
- HTML / CSS (Bootstrap o Tailwind opcional)
- JavaScript (Chart.js para gráficos)
